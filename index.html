PROJECT 01

渠道伙伴分层与年度经营框架

在行业承压周期中，提前锁定渠道伙伴资源与年度承诺，并建立可持续的履约与激励闭环。

业务难题

渠道伙伴差异大，复杂政策难以形成清晰的经营预期与有效承诺。

策略动作

多维伙伴画像、重要性四象限分层、差异化资源支持与阶梯激励设计。

关键结果

新增507家伙伴；Q1前有效签约1,150家，锁定约7万台年度承诺。

可复用方法

用画像识别差异，用分层政策配置资源，用过程监控动态校准激励。

3站伙伴路演约7万台年度承诺全年5.3万台销售目标达成
PROJECT 02

智能组品全链路供给建设

在大店增长承压阶段，以低成本、可控、可规模化的方式补齐货盘质量与丰富度，并通过端到端组品链路提升售卖效果。

业务难题

合作方组套控单能力不均，中小商家缺少数据分析与套餐设计能力，货盘质量、丰富度与用户体验仍有提升空间。

策略动作

建立“招—管—培—汰”的BPO全周期基建；以货盘诊断、智能/人工组套、谈单上单、审核、分发和复盘串联端到端闭环。

质量与工具

围绕图片、标题、详情、价格、使用条件建立分流审核标准；培训专家团队，并推动辅助字段、分层派单与审核助手等能力升级。

可复用方法

将供给问题拆为标准、组织、流程、工具与经营反馈五个模块，以规则保障质量、以BPO承接规模、以数据持续迭代。

月均70–80万审核量准确率 60% → 92%量级 +4% / 成本 -5%套餐日均订单 +58.8%访购率 +3.3pp新签门店月ARPU +85.8%审核后商品单产值约2倍提升
PROJECT 03

景点商品标准化与优势供给放大

以商品信息治理为基础，建立“标准化—精准识别—全场域分发—增长验证”的供给经营闭环。

业务难题

商品信息标准不统一、票种命名自定义程度高，影响供给识别、货架呈现与后续营销资源的精准匹配。

策略动作

重建店品双层标准体系，完善POI字段、类目与票种核心要素；通过规则治理识别具备丰富度与价格力的优势供给。

全场域放大

将识别出的优势供给协同应用到货架、搜索推荐与营销场，持续观察UV、CVR和交易结果，反哺标准与招商策略。

可复用方法

将标准化从信息治理升级为经营基础设施，让供给更容易被识别、匹配、分发和验证增长价值。
